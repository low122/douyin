# Douyin Knowledge Base

Turns saved Douyin videos into searchable moments, so that asking a question lands the user on the exact few seconds that answer it — and tells them what those seconds said.

## Language

**Video** (视频):
A single Douyin video a user has sent into the system. The system keeps its metadata and the text derived from it, never the video file itself.
_Avoid_: 影片 on its own (ambiguous with Moment), post, clip

**Moment** (片段):
A time-bounded span inside a Video carrying one self-contained piece of information. It has a start and end time, a summary of its own, and is the unit a search returns.
_Avoid_: 节点, segment, chunk, snippet, highlight
